# Repository instructions

These instructions apply to every website in this repository.

## Verification

- Do not perform visual verification unless the user explicitly requests it.
- Do not take screenshots, inspect rendered pages, run browser or native-app verification, or perform viewport/device checks to validate changes unless requested.
- A request to implement or adjust a UI does not implicitly authorize visual verification.
- Use proportionate nonvisual checks instead: source inspection, typechecking, builds, and relevant tests when necessary.
- Do not claim that an appearance was visually verified when no requested visual check was performed.

## CV project copy

- Keep project descriptions short enough to fit within three lines at the standard desktop card width (300px). This is an editorial guideline: revise the wording when needed rather than clipping, truncating, line-clamping, or imposing a maximum text height in code.
